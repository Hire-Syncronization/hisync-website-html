TEAM & FOUNDER PHOTOS
=====================
The website loads these photos local-first, with an automatic fallback
to the current live site (hisync.in/images/our_team/) if a file is
missing here. Once you place the files below in this folder, the site
becomes fully self-hosted — no code changes needed.

Copy these 8 files from your current site (hisync.in/images/our_team/):

  rohit.webp          - Rohit Gaur (Founder)
  amit.webp           - Amit S. Chauhan (Founder)
  ujjwal.webp         - Ujjwal Agrawal (Founder)
  abhishek.webp       - Abhishek Rajput
  abhay.webp          - Abhay Sagar Kargetti
  suraj-thakur.webp   - Suraj Thakur
  umesh.webp          - Umesh Goswami
  ayush.webp          - Ayush Agrawal

Recommended: square crops, ~300x300px, .webp format (same as current).
If a photo is missing in both places, the site shows the person's
initials in a branded circle instead.
